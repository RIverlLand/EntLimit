# 开发进度

更新日期：2026-10-19。本页记录源码进度；安装包包含的功能以对应 Release 为准。

## 本轮完成

- 优化规则页面的监控状态和保存操作；完善 Python 解释器发现与手动选择，练习运行临时文件优先使用应用数据目录。
- 补充配置说明，说明字段、默认值、边界及编辑方式，见 [配置说明](CONFIGURATION.md)。
- 新增 [20 道 Python 循序练习](../content/packs/python-practice-20/README.md)，分五个离线题包，覆盖哈希、滑动窗口、矩阵、栈、二分、递归、动态规划与实用数据处理。
- 每题提供空白函数骨架、明确约定、提示、参考解与复杂度说明，部分题另有备用解法。题包可手动导入，已有题包不需要 API。
- 修复首次导出题包提示词时 JSON Schema 初始化失败的问题，并加入回归检查。
- 通过兼容 Chat Completions 的服务完成本地连接与出题验证。个人 API 配置、DPAPI 密钥文件、测试程序和测试数据留在仓库之外。
