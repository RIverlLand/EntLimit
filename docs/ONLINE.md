# 在线能力与密钥

EntLimit 离线功能不依赖 Codex、Claude 或模型账户。开发协作与用户运行应用是分开的；发布包不包含开发者密钥、账户登录信息或个人数据。

## 配置

打开“API 与扩展”，填写兼容 Chat Completions 的 API 基础地址（通常以 `/v1` 结尾，或完整 `/chat/completions` 地址）、服务商实际支持的模型名称及 API Key。点击保存后，密钥不会再回填到输入框。留空可以继续使用这个相同端点的已保存密钥；删除按钮只删除密钥，保留模型和地址。改变端点需要为新端点重新填写密钥。

密钥使用 Windows 当前用户 DPAPI 加密，保存为 `api-key.dpapi`；文件在创建时即设置仅当前 SID 的 ACL 和所有者，以随机临时文件、原子替换保存，不进行明文持久化。`api-settings.json` 只保存端点和模型。解密失败会要求重新配置，不回退为明文。不要把自己的用户数据目录发给他人；DPAPI 密文也不会被放进安装包。DPAPI 不防同一 Windows 用户下的恶意程序；练习运行器仅供可信个人代码，不是安全执行未知代码的沙箱。

## 发送范围

只有三个主动操作联网：连接测试发送短问候；“在线分析”发送当前题目标题、要求和代码快照；“在线生成草稿”发送题包格式、现有题目目录、主题目录及你输入的生成要求。既有答案、学习历史、受管控程序列表和密钥均不进入模型提示词。Bearer 密钥仅作为认证头发送至你配置的目标；端点变化、重定向和错误响应不会把它转发到其他目标。代码内自行写入的内容会随显式分析发送，请先检查当前代码。

远程连接必须 HTTPS；只允许无密钥的本机回环 HTTP 服务，不将 Bearer 凭据明文发送至 HTTP。禁用自动重定向和系统代理，不自定义绕过 TLS 验证。超时 60 秒、回复最多 256 KiB，可随时取消。不显示服务端错误正文或底层异常详情，不写请求/回复日志。响应若直接回显当前密钥会进行遮盖；这不能保证遮盖恶意服务以任意编码重构的内容，因此只配置自己信任的服务商。

在线分析只提供建议，不运行代码、不判定通过、不授予或延长娱乐许可。编辑后旧建议显示版本过期，切题不会把旧建议误用于新题。本地 AST 分析与本地判题继续可用。

## 题包

没有 API 时，点击“导出 AI 提示词”，将导出的范本和题目目录交给自己使用的 AI，获得 JSON 文件后“读取 JSON 文件→预览题包→逐题核对→确认所选项并导入”。有 API 时可在应用中生成草稿，后续仍经过同一预览流程。所有应用内生成题强制标为 AI 待人工审核，未声称搜索或验证来源，不自动导入。新增默认为新增，相同/更新/相似项默认跳过；更新需明确选择。导入已打开题目的更新后，旧题面暂时只读待重选，防止按旧题干向新规则提交。

需要更多内容可以请开发者制作并提供题包。本轮没有联网爬题、课程下载、作文自动评分、语音识别或插件市场；英语/语文的填空和选择由内容包复用现有能力。详见 [题包规范](CONTENT-PACKS.md)。
