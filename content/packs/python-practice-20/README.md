五个可独立导入的 v1 题包，每包四道 Python 代码题。全部题目是 AI 辅助原创，不是爬取或转载的 LeetCode / 课程原题。

## 使用

1. 在 EntLimit 的“API 与扩展”页选择“读取 JSON 文件”。
2. 依次选择这五个 JSON 文件，先预览题干、参考解和检查用例，再确认导入。
3. 回到“今天的练习”，选择“编程 · Python”。推荐模式优先未通过题，也可以选随机。

题包只含离线内容，导入不需要 API，不会下载解释器或执行参考代码。需要已有的 Python 3.8+ 才能提交编程题。参考解默认折叠；答题框仅提供函数签名和 pass，不预填答案。

导入后仍沿用原有许可规则：通过完整判题才记录学习；导入、预览、查看答案、QA 校验都不算用户已通过。重复导入应显示“相同”，无需重复新增。

## 学习内容

每题包含明确输入输出、边界约定、分步提示、高效参考实现、复杂度解释及六至七个用例；部分题另有可运行的 Python 惯用写法或算法对照。大多面向 5–10 分钟练习，部分递归题预计可到 12 分钟。

这些是 20 道正常模式代码原题，尚未额外提供对应的短复习场景题。讲解与有限测试并非对所有输入正确性或数学最优性的证明。

## 校验记录

- 应用自身 v1 Schema 验证：20 题、5 包，每包小于 48 KiB。
- 固定用例：共 123 个，含空输入、重复、Unicode、边界及不修改输入的要求。
- 20 份参考实现与 17 份备用解法通过应用实际运行器检查。
- 独立答案与随机对照：固定种子 20261019，每题 100 组随机输入及额外边界，共 3,930 次结果与输入不变性检查通过。
- 本地验证使用 Python 3.14；所有参考实现另通过 Python 3.8 语法解析检查。
- JSON 本身不包含任何个人数据、API 配置或密钥。
